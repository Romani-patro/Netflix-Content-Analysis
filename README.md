# Netflix Content Analysis Dashboard

## Project Overview
This project analyzes Netflix movies and TV shows using Python, MySQL, and Tableau Public. It explores content distribution, release trends, countries, genres, and ratings.

## Tools and Technologies
- Python
- MySQL
- Tableau Public
- VS Code

## Key Analysis
1. Movies vs TV Shows distribution
2. Content by release year
3. Top 10 countries
4. Top 10 genres
5. Content added by year
6. Ratings distribution

## Project Workflow
- Cleaned and prepared the Netflix dataset using Python.
- Performed exploratory data analysis.
- Imported 8,807 records into MySQL.
- Wrote SQL queries to analyze Netflix content.
- Created visualizations and an interactive dashboard in Tableau Public.
